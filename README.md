# Rogers Fotografias

Portfólio fotográfico responsivo em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — página principal
- `css/style.css` — identidade visual e responsividade
- `js/main.js` — menu mobile, filtros e lightbox
- `assets/images/` — fotografias selecionadas

## Para editar

Substitua as imagens da pasta `assets/images/` mantendo os nomes usados no `index.html`, ou altere os caminhos dos elementos `<img>` e `data-image`.
